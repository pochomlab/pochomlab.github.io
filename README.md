This repository hosts the static website for PochomLab.

## 🧪 PochomLab

生成AIと人間の判断を往復しながら、
創作・技術・出版をひとつの流れとして扱う小さな実験室です。

本リポジトリでは、静的サイト構造（HTML5UP Landed）を基盤に、
絵書・ZINE・アプリケーションが連動する創作環境を公開しています。

## 📂 Contents

- index.html  
トップページ。世界観・構造・連動アプリの概要を掲載。

- egaki-sho.html  
長編作品『ポチョム菌の絵書』の紹介ページ。

- egaki-sho-create.html  
制作ログをまとめた ZINE シリーズの紹介ページ。

- application.html  
デスクトップペット・AIローカルハブ・2Dゲームなど、
物語世界と連動するアプリケーション群。

- about.html  
PochomLab の概要と運営者情報。

## 🧩 Structure

本サイトは HTML5UP Landed をベースに、
Astro などのビルド工程を用いない 純HTML＋CSS構成で運用しています。
